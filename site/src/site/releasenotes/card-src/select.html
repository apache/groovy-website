APACHE GROOVY 6 · CHANNEL SELECT
ChannelSelect · incubating

Wait on many channels, commit to exactly one

Offers that send as readily as they receive, a precondition on any branch, and deadlines that are branches too
MIXED OFFERS · SEND OR RECEIVE 
import static groovy.concurrent.ChannelSelect.*

def r = await offers(send(ping, 1),
                     receive(pong)).select()

if (r.send) commit()  // my opener went
else        read(r.value)  // peer's did
“I will send my opener, or take my peer’s if it sends first.” The mixed choice of CSP, and the send cases of Go’s select.
GUARDS & TIMERS · PER BRANCH 
def sel = offers(
    receive(work).when { held.size() < cap },
    after(100)).fair()

def r = await sel.select()
if (r.timeout) idle()  // quiet 100 ms
A guarded-off branch keeps its index, so r.index means the same thing either way. Listed last, after(0) is Go’s default clause.
AND YOU PICK WHICH READY BRANCH WINS
priority — the first listed, and the default ·  fair() — rotates, so every ready branch is taken within n calls ·  random() — uniform, as Go chooses ·  guards conjoin with the positional flags of select(boolean...)
Exactly one branch commits. The losing branches are left untouched — nothing taken, nothing put back.
