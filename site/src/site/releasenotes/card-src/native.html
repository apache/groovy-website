Dynamic Groovy, compiled ahead of time

Dispatch stays dynamic — the call site just links once instead of retargeting
✗  THE OLD ADVICE
“@CompileStatic everything, turn indy off.”
Which is to say: stop being dynamic.
And it still didn't get you there — dynamically compiled code in your dependencies, Groovy's own modules included, crosses dynamic call sites you can't recompile.
✓  GROOVY 6
Fully dynamic source. Stock compilation.
No annotations, no flags — the AOT link mode switches on when it detects an AOT build.
It changes linking, not compilation, so already-published indy-compiled jars come along without being recompiled.
Early days. This changes how Groovy links dispatch, not one AOT toolchain — more to come in Groovy 7.
